# Lineage and licence

## Origin

Kvasir began as a clean import of LearnHarness by Amos Blomqvist.

- Upstream repository: https://github.com/amosblomqvist/learnharness
- Imported commit: `dc4c398d5167865b84b0ccb3ec809eb88bf8f65f` (29 October 2026, version 0.4.0)
- Import method: source tree copied into a new repository with fresh git history. No upstream remote is configured.

## Licence obligations

LearnHarness is licensed AGPL-3.0-only. Kvasir is a modified version and is also AGPL-3.0-only. In practice this means:

1. Keep the `LICENSE` file unchanged.
2. Keep upstream copyright notices. Add Kvasir notices next to them; never replace them.
3. State that the files were modified (this file and the README do that).
4. If Kvasir is ever offered to other people over a network, offer them the full source of the running version.
5. Any code taken from Kvasir by others stays under AGPL.

This is orientation, not legal advice.
